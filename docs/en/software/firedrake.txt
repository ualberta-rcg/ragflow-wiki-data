[https://www.firedrakeproject.org/ Firedrake] is an automated system for the solution of partial differential equations using the finite element method (FEM). 

Please note that every release of Firedrake requires a specific version of PETSc, several other modules and Python wheels.

= Installation =

Please note that all modules must be loaded before creating and/or activating the Python virtualenv.
<tabs>
<tab name="Firedrake 2026.4.1">
{{Commands
|module load StdEnv/2023  gcc/12.3  openmpi/4.1.5  python/3.14  mpi4py/4.1.0
|module load vtk/9.4.2  symengine/0.14.0  libspatialindex/2.1.0  petsc/3.25.1
|virtualenv venv-firedrake
|source venv-firedrake/bin/activate
|pip install -U pip
|pip install --no-index  msgpack  tables{{=}}{{=}}3.11.0  pytools{{=}}{{=}}2026.1.1  immutabledict
|pip install --no-index  firedrake[check]{{=}}{{=}}2026.4.1
}}
The above has been tested with <code>python/3.14</code>, <code>python/3.13</code>, <code>python/3.12</code> and <code>python/3.11</code>.
</tab>

= Running jobs =

<tabs>
<tab name="Firedrake 2026.4.1">
{{File
  |name=job_firedrake_multigrid.sh
  |lang="bash"
  |contents=
#!/bin/bash
#SBATCH --time=0-00:15:00  # d-hh:mm:ss
#SBATCH --ntasks=2
#SBATCH --mem-per-cpu=4000M
export OMP_NUM_THREADS=${SLURM_CPUS_PER_TASK:-1}

# Load modules
module load StdEnv/2023  gcc/12.3  openmpi/4.1.5  python/3.14  mpi4py/4.1.0
module load vtk/9.4.2  symengine/0.14.0  libspatialindex/2.1.0  petsc/3.25.1

# activate virtualenv
source venv-firedrake/bin/activate

# run MPI job
# example from: https://firedrakeproject.org/demos/geometric_multigrid.py
srun  python  geometric_multigrid.py

= Optional dependencies =
Firedrake has a number of [https://www.firedrakeproject.org/install.html#optional-dependencies optional dependencies] that can be installed into the [[Python#Creating_and_using_a_virtual_environment|virtualenv]]:

* '''SLEPc''' and slepc4py are part of the <code>petsc</code> module and always available.
* '''netgen''': We provide [[Python#Available_wheels|precompiled wheels]] for <code>ngsPETSc</code> and <code>netgen_mesher</code>.
* '''[[PyTorch]]''': We provide [[Python#Available_wheels|precompiled wheels]] for <code>torch</code>.
* '''Jax''': We provide [[Python#Available_wheels|precompiled wheels]] for <code>jax</code>.
* '''[[VTK]]''': The module <code>vtk/9.4.2</code> is compatible with <code>python/3.14</code>, <code>python/3.13</code>, <code>python/3.12</code> and <code>python/3.11</code>.
