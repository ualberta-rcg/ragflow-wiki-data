<div lang="en" dir="ltr" class="mw-content-ltr">
A job submission web page should appear in your browser.  Configure the resources required for your interactive desktop session and click on ''Launch'' or ''Start''.  If either accelerated graphics or computations will be conducted from within your desktop session, be sure to specify a GPU resource.  Load an Ansys module on the desktop.  If you started a JupyterLab-powered desktop, this can be done by clicking in the menu on the left; however, if you started an OnDemand desktop manually, type <code>module load ansys/version</code> on the command line.  To start one of the common Ansys programs such as Fluent, CFX, Workbench, and so forth, refer to the following sections which provide advice for setting environment variables and arguments required by VirtualGL or Mesa-based graphical environments, depending on whether a node with a GPU resource was specified or not.
</div>  

=== Fluent === 


<div lang="en" dir="ltr" class="mw-content-ltr">
To start Ansys Fluent from the command line on an OnDemand desktop, open a terminal window and run
</div>


::: <code>module load StdEnv/2023 ansys/2025R2.04</code>
::: <code>fluent</code>


<div lang="en" dir="ltr" class="mw-content-ltr">
When the Fluent Launcher popup selector panel appears, click on the ''Environment tab'' and copy/paste the environment variable settings from one of the following two subsections, depending on whether you started your OnDemand session with a GPU for graphical acceleration. Do not include the text in parentheses as these are comments, and do not put <code>export</code> in front of any variable name. If the graphics console window becomes corrupted when starting the GUI, restart Fluent, setting <code>HOOPS_PICTURE=null</code> to disable the creation of the graphics panel.
</div>

<b>Compute Node (sans GPU)</b>


<div lang="en" dir="ltr" class="mw-content-ltr">
::: <code>I_MPI_HYDRA_BOOTSTRAP=ssh</code> &nbsp;&nbsp;&nbsp;&nbsp; (required on Nibi w/ intelmpi)
::: <code>HOOPS_PICTURE=opengl2-mesa</code> &nbsp;&nbsp; (version 2025R1 or newer)
::: <code>HOOPS_PICTURE=x11/lin</code> &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;   (version 2024R2.04 or older)
::: Click on the ''Start'' button.
</div>


<b>Nœud de calcul (avec GPU)</b>


<div lang="en" dir="ltr" class="mw-content-ltr">
To use hardware accelerated graphics with Fluent on Nibi, choose a t4 (15GB) from the GPU selector pulldown list for your OnDemand desktop session.  Doing this ensures that the environment variables used by VirtualGL to enable accelerated OpenGL graphics calls are automatically set up inside your desktop environment for the current session.  Once your desktop appears, open a terminal window and start Workbench as follows
::: <code>I_MPI_HYDRA_BOOTSTRAP=ssh</code> &nbsp;&nbsp;&nbsp;&nbsp; (required on Nibi)
::: <code>HOOPS_PICTURE=opengl2</code> &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; (version 2025R1 or newer)
::: <code>HOOPS_PICTURE=opengl</code> &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; (version 2024R2.04 or older)
::: Click on the ''Start'' button.
</div>


<div lang="en" dir="ltr" class="mw-content-ltr">
NOTE: When running Fluent on Nibi, the environment variable <code>I_MPI_HYDRA_BOOTSTRAP=ssh</code> must be manually set; otherwise, Fluent will crash when started inside OOD Compute Desktop sessions when intelmpi is used.  Error output such as the following will be created.  Should this occur, completely exit Fluent, cleanly shut down Workbench and start over.
 [mpiexec@g4.nibi.sharcnet] Error: Unable to run bstrap_proxy on g4.nibi.sharcnet (pid 2251587, exit code 256)
 [mpiexec@g4.nibi.sharcnet] poll_for_event (../../../../../src/pm/i_hydra/libhydra/demux/hydra_demux_poll.c:157): check exit codes error
 [mpiexec@g4.nibi.sharcnet] HYD_dmx_poll_wait_for_proxy_event (../../../../../src/pm/i_hydra/libhydra/demux/hydra_demux_poll.c:206): poll for  event error
 [mpiexec@g4.nibi.sharcnet] HYD_bstrap_setup (../../../../../src/pm/i_hydra/libhydra/bstrap/src/intel/i_hydra_bstrap.c:1063): error waiting for event
 [mpiexec@g4.nibi.sharcnet] Error setting up the bootstrap proxies
</div>

=== CFX === 


<div lang="en" dir="ltr" class="mw-content-ltr">
When starting CFX from an OnDemand desktop, the following arguments may be specified on the terminal window command line.  Use <code>ogl</code> if you requested a GPU when the desktop was started and use <code>mesa</code> if you did not.
</div>


<div class="mw-translate-fuzzy">
::: <code>cfx5 -graphics mesa</code>   (sans GPU requested)
::: <code>cfx5 -graphics ogl</code>    (avec GPU requested)
</div>

=== Workbench === 


<div lang="en" dir="ltr" class="mw-content-ltr">
This section shows how to start Workbench (and optionally Fluent) on either an OnDemand desktop or a JupyterLab desktop.
</div>

<span id="OnDemand_desktop"></span>
==== Bureau OnDemand==== 

<div lang="en" dir="ltr" class="mw-content-ltr">
<b>Compute node (no GPU requested) or basic desktop</b>
</div>


<div lang="en" dir="ltr" class="mw-content-ltr">
If accelerated graphics are not required for your desktop session, specify ''GPU Node'' to select a compute node without a GPU for your OOD session.  Doing this uses Mesa software emulation for opengl calls, instead of running on a more expensive and difficult to reserve GPU node.
::: <code>module load StdEnv/2023 ansys/2025R2.04</code>
::: <code>runwb2</code>
</div>

<div lang="en" dir="ltr" class="mw-content-ltr">
To start Fluent from within Workbench, click on ''Fluid Flow (Fluent)'' or ''Fluent with Fluent Meshing'' in the ''Analysis'' menu on the left, and click on ''Setup'' in the centre canvas ''Fluid Flow (Fluent)'' popup.  Once the ''Fluent Launcher'' selector panel popup appears, click on the ''Environment'' tab and copy/paste the following environment variable settings:
::: <code>I_MPI_HYDRA_BOOTSTRAP=ssh</code> &nbsp;&nbsp;&nbsp;&nbsp; (required on the Nibi cluster only when using intelmpi)
::: <code>HOOPS_PICTURE=opengl2-mesa</code> &nbsp;&nbsp; (optional for 2025R1 or newer)
::: Click on the ''Start'' button.
</div>


<b>Nœud de calcul (avec GPU)</b>


<div lang="en" dir="ltr" class="mw-content-ltr">
If accelerated graphics are required on the Nibi cluster, choose t4 (15GB) from the GPU selector pulldown list for your OnDemand desktop session.  Doing this will ensure that the environment variables used by VirtualGL to enable accelerated OpenGL graphics calls are automatically set up inside your desktop environment for the current session.  Once your desktop appears, open a terminal window and start Workbench as follows
::: <code>module load StdEnv/2023 ansys/2025R2.04</code>
::: <code>runwb2</code>
</div>


<div lang="en" dir="ltr" class="mw-content-ltr">
To start Fluent from within Workbench, click on ''Fluid Flow (Fluent)'' or ''Fluent with Fluent Meshing'' in the left-hand ''Analysis'' menu, and click on ''Setup'' in the centre canvas ''Fluid Flow Fluent'' popup.  Once the ''Fluent Launcher'' selector panel popup appears, click on the ''Environment'' tab and copy/paste the following environment variable settings.
::: <code>I_MPI_HYDRA_BOOTSTRAP=ssh</code> &nbsp;&nbsp;&nbsp; (required on the Nibi cluster only)
::: <code>HOOPS_PICTURE=opengl2</code> &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;(optional for 2025R1 or newer)
::: Click on the ''Start'' button.
</div>

 <code>module load StdEnv/2023 ansys/2025R2.04</code> (or 2025R1, 2025R1.02, 2025R2)
