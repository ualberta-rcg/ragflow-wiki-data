Une étape importante en développement logiciel, particulièrement en Fortran et C/C++, est l'utilisation d'un logiciel de débogage pour détecter et identifier l'origine des erreurs d'exécution (par exemple les fuites de mémoire, les exceptions de virgule flottante, etc.). Après avoir éliminé les erreurs, la prochaine étape est d'utiliser un logiciel de profilage pour déterminer le pourcentage du temps d'exécution pour chacune des sections du code source avec un scénario de test représentatif. Un profileur peut fournir de l'information sur le nombre de fois qu'une fonction est appelée, quelles sont les fonctions qui l'appellent ou encore combien de millisecondes en moyenne coûte chaque appel.   

<span id="Debugging_on_a_cluster"></span>
= Déboguer sur une grappe =

<b>Puisque les sessions de débogage sur les nœuds de connexion sont à éviter, il faut plutôt passer par une tâche interactive.</b> Les options sont&nbsp;:

* utiliser la commande Slurm <code>salloc ...</code>; voir <b>[[Running_jobs/fr#Tâches_interactives|Tâches interactives]]</b>;
* ouvrir une session JupyterLab; voir <b>[[JupyterLab/fr#Lancer_JupyterLab|Lancer JupyterLab]]</b> pour les instructions de connexion et pour connaître les [[JupyterLab/fr#Applications_préconstruires|applications préconstruites]];
* démarrer une session de bureau distant pour faire du profilage visuel; voir <b>[[JupyterLab/fr#Desktop|cette partie de la page JupyterLab]]</b> ou  <b>[[Open_OnDemand/fr#Introduction|les références pour Trillium ou Nibi dans la page Open OnDemand]]</b>.

<span id="Scalasca_profiler_(scalasca,_scorep,_cube)"></span>
== Profileur Scalasca (scalasca, scorep, cube) ==

Scalasca est un ensemble d'outils <i>open source</i> avec une interface graphique pour le profilage parallèle avec GPU. Ces outils sont disponibles pour <b>gcc 9.3.0</b> et <b>OpenMPI 4.0.3</b>, dans des architectures AVX2 et AVX512. Chargez l'environnement avec

<code>module load StdEnv/2020 gcc/9.3.0 openmpi/4.0.3 scalasca</code>

La version courante est <b>2.5</b>. Vous trouverez plus d'information et des exemples de flux de travail dans [https://apps.fz-juelich.de/scalasca/releases/scalasca/2.5/docs/manual/ Scalasca User Guide].
