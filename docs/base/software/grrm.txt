<!--T:1-->
Global Reaction Route Mapping ([https://global.hpc.co.jp/products/grrm23/ GRRM]) is commercial software for the analysis of chemical reaction pathways. 
The program is capable of exhaustively exploring the potential energy surface of a collection of atoms, automatically finding molecular geometries of reactants, transition states and products. 
GRRM23 works in conjunction with quantum chemistry software such as [[Gaussian|Gaussian 16]] and [[ORCA]].

<!--T:2-->
== License ==
To obtain a license and pricing, submit a request at [https://global.hpc.co.jp/contact/ HPC SYSTEMS Inc.] or contact [mailto:ke-kimura@hpc.co.jp Kenshiro Kimura]. 

<!--T:19-->
GRRM23 uses a floating license approach for validating users; it requires setting up a license server.
For this, HPC SYSTEMS Inc. allows users to connect to license servers at their company site in Japan at no additional cost. 
Alternatively, a license server can be set up at your university in Canada. 
For more about either license server option contact technical support at [https://global.hpc.co.jp/contact/ HPC SYSTEMS Inc.]

== Installation ==
After buying a license, users will receive a link and instructions to download a compressed <code>tar.bz2</code> file. Download the file and follow the instructions below.

<!--T:4-->
In your home directory, create a directory for the installation and another one for the executables:
</translate>
<pre>
mkdir GRRM23_Installation
mkdir GRRM23_RUN
</pre>

<translate>
<!--T:5-->
Move the compressed GRRM23 file to <code>$HOME/GRRM23_Installation</code> and extract it there:
</translate>
<pre>
cd GRRM23_Installation
tar xjf GRRM23.tar.bz2
</pre>

<translate>
<!--T:6-->
Verify that this has created an installation script (install.sh).
Then from <code>$HOME/GRRM23_Installation</code>, execute the script as follows:
</translate>
<pre>
./install.sh /home/user/GRRM23_RUN
</pre>

<translate>
<!--T:7-->
The installation will prompt you to the following screen:
</translate>
<pre>

Intel MPI installation prefix = /home/user/GRRM23_RUN/mpi-rt

Type “Y” and press “Enter” to proceed with the installation. Once the
installation is finished, a “GRRM INSTALLATION DONE” message should appear:

== Usage ==
For input examples, please refer to the [https://afir.sci.hokudai.ac.jp/manual/ GRRM23 user’s manual].
In most cases GRRM23 requires only one input file (<code>Job.com</code>) containing the Cartesian coordinates of a molecule and methodology options.
In some other cases, GRRM23 requires the output of a previous GRRM23 job.

<!--T:13-->
=== Sample Slurm script for a single node ===
For a single node (<code>--nodes=1</code>) and 12 cores (<code>--ntasks-per-node=12</code>), running from your <code>/scratch</code> directory:
</translate>
<pre>
#!/bin/bash
#SBATCH --time=24:00:00
#SBATCH --nodes=1
#SBATCH --ntasks-per-node=12
#SBATCH --mem-per-cpu=4000M

module load gaussian/g16.c01
export GAUSS_SCRDIR=/home/user/scratch/

GRRM23p Job -p1 -s80000
</pre>

<translate>
<!--T:14-->
* <code>-p1</code>: number of parallel processes. 
* <code>-s80000</code>: signals when (in seconds) to create a checkpoint file so that an interrupted job can be restarted properly.  Notice that 80000 second is about 22 hours.  This time should be less than the <code>--time</code> you request from Slurm.

<!--T:20-->
<b>Multiple nodes not supported:</b>
Due to the Gaussian licenses at Fir and Nibi, GRRM23 can be used with Gaussian only on a single node.

=== Example using ORCA === <!--T:15-->
</translate>
<pre>
#!/bin/bash
#SBATCH --time=18:00:00
#SBATCH --nodes=1
#SBATCH --ntasks-per-node=16
#SBATCH --mem-per-cpu=4000M

module load StdEnv/2023  gcc/12.3  openmpi/4.1.5
module load orca/6.0.0

GRRM23p glucose -p1 -h15
</pre>
